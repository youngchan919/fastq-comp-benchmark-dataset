## 检查已下载文件

请使用新的、按版本区分的下载目录，例如 `downloads/v1.1.0`。现有下载任务和目录没有更改。从该目录内包含 `data/` 文件夹的位置运行：

```bash
cd YOUR_DOWNLOAD_FOLDER
md5sum -c /path/to/fastq-comp-benchmark-dataset/checksums/MD5SUMS
```

匹配表示完整下载文件与发布者提供的 MD5 值一致。缺失文件会报告为缺失，这不等于证明已下载内容损坏。`.part` 后缀、最终文件名或大小相符，均不能单独证明文件完整。没有发布者校验和的文件还需按[准备说明](../docs/preparation.md)执行进一步检查。
