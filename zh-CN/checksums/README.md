## 检查已下载文件

在包含下载目录 `data/` 的文件夹中运行以下命令，并将仓库路径替换为本机实际路径：

```bash
cd YOUR_DOWNLOAD_FOLDER
md5sum -c /path/to/fastq-comp-benchmark-dataset/checksums/MD5SUMS
```

匹配结果表示完整的下载文件与发布者提供的 MD5 一致。若文件缺失，命令会报告缺失；这不能证明已下载内容损坏。文件名带 `.part`、使用最终文件名或大小相符，都不能单独证明下载完整。没有发布者校验和的文件，还需按[准备说明](../../docs/preparation.md)执行其他完整性检查。
