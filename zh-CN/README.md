# FASTQ 无损压缩基准数据集

[English](../README.md) · **简体中文**  
数据集版本：v1.0.0 · [版本说明](VERSIONING.md)

这份数据集用于测试 FASTQ 文件的无损压缩和解压。我们选择了 52 组公开数据，覆盖常见的测序技术和用途。每组数据都给出选择理由、下载地址和使用方法。这个仓库只保存清单和说明，测序文件需要另外下载。

基准输入是**未压缩的 FASTQ 文件**。下载得到的 gzip 文件需要先解压。无损恢复要求还原相同的读段名称、序列、质量字符、顺序和格式，而不只是得到相同的生物序列。

## 数据集包含什么

| 项目 | 数量 |
| --- | ---: |
| 数据集 | 52 |
| 待下载文件 | 115：114 个 gzip FASTQ 文件和 1 个 BAM 文件 |
| 清单所列下载总字节数 | 1,419,456,345,104 字节（1.419 十进制 TB） |
| 有发布者 MD5 值的文件 | 73 |
| 建议参考序列版本 | 18 |

数据包括人类及其他生物的基因组、整体和单细胞 RNA、标签与空间读段、染色质文库、靶向标记、分离株和混合群落，也涵盖多种技术产生的短读段与长读段。一个数据集可以是一次双端测序的完整输出、一个细胞的数据，或一份由多次测序运行组成且名称明确的文库。请保留清单列出的每个文件。

## 下载

需要 Python 3.8 或更高版本以及 GNU wget。请将下载文件放在单独的目录中。

```bash
# 列出文件，不执行下载。
python3 download_benchmark.py --dry-run

# 下载所有入选文件；保留现有有效文件和可续传的部分文件。
python3 download_benchmark.py --output downloads --jobs 8

# 也可只下载指定数据集的全部清单文件。
python3 download_benchmark.py --ids 10,30 --output downloads
```

下载程序会在可用时核对清单中的文件大小和发布者 MD5 值。未完成的文件保留为 `.part`，程序不会覆盖已有的完整文件。校验和不匹配时会报告错误，不会将其当作通过。仅大小相同，验证力度低于校验和匹配。共享的 [MD5SUMS 文件](../checksums/MD5SUMS)列出全部 73 个发布者提供的值；[核验表](../checksums/verification.tsv)标明记录日期，并不表示所有文件都已下载完成。缺失校验和或仍在进行的本地下载不会形成新的数据集版本。

Data 8 是一个 CNGB 文件 `WY_reads.fq.gz`，不是一对文件或两个分块。清单所列文件大小为 130,270,589,600 字节，没有发布者 MD5 值。Data 6 是待按固定规则导出为 FASTQ 的 BAM 文件。两者的确切序列总产量仍未知。

## 准备和测试

请按[完整准备说明](docs/preparation.md)处理数据。每个 gzip 源文件都要检查完整数据流，单独解压，并记录 FASTQ 字节数和 SHA-256。不要合并配对文件、不同测序运行或分块，也不要改动文件字节。Data 6 使用文档规定的 SAMtools 1.22/htslib 1.22 导出规则；该规则已通过合成测试，但尚未用于真实 BAM。

建议的参考序列版本尚未在此处下载或验证，也不保证与样本匹配。空间掩码和标签定义可用于特定解释或自定义参考方案，但不是通用 FASTQ 无损压缩的必要输入。

归档调查覆盖截至 2026 年 9 月 30 日的存量及此前 12 个月的公开增量，并沿用原始来源和检索日期。全球统计包含中国。归档托管地不能说明商业生产地点或产量。报告详述调查结果及其限制。

## 重建和检查仓库

```bash
# 仅运行小型合成测试，不读取真实测序数据。
python3 -m unittest discover -s tests -v

# 重建英文文档和表格；需要安装 XlsxWriter。
python3 tools/build.py
```

固定 BAM 导出规则的测试需要 SAMtools 1.22/htslib 1.22。源文件完整性检查、文档检查和压缩基准测试回答的是不同问题。本仓库没有报告实测压缩比或吞吐量；参见[验证范围](docs/validation.md)。尚未检查原生 Office 分页效果。

各语言版本共用同一份数据清单；数据编号、文件身份和数量均按清单记录。
