# 数据集版本

[English](../VERSIONING.md) · [简体中文首页](README.md)

当前集合版本为 **v1.0.0**。共享的 [VERSION 文件](../VERSION) 和目录清单中的 `dataset_version` 标识数据集版本；`schema_version` 标识清单格式，两者含义不同。

数据集版本固定了入选文件、完整输入单位、参考序列版本，以及决定准备后 FASTQ 字节内容的规则。部分源文件校验和和准备结果仍未知；版本号并不表示所有文件均已下载或验证。文件核验状态另见带日期的[核验表](../checksums/verification.tsv)。

- **新增输入字节或改变科学定义：**添加/删除文件，或改变文件内容、参考序列或准备后字节规则时，应采用新的数据集版本，例如 v2.0.0。不要改动先前发布的版本标签。
- **输入不变、仓库内容改进：**如果只更正文档、兼容性工具或增加不改变测试输入的核验结果，可采用补丁版本，例如 v1.0.1。
- **年度复核：**每年重新审视证据和数据可用性。复核并不要求更换文件或创建新版本。

发布标签不可变：已发布标签必须继续指向同一 Git commit。需要更正时，应创建新标签。报告基准结果时，请同时记录数据集版本和准备后 FASTQ 的哈希。发布者校验和、下载文件哈希和准备后 FASTQ 哈希分别对应不同文件内容，应分别标明。
