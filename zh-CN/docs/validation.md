# 验证范围

[English home](../../README.md) · [简体中文](../README.md)

本地库存包含 52 个数据集、115 个源对象（114 个 gzip FASTQ 文件和 1 个 BAM）、1,419,456,345,104 个登记源字节，以及 18 项带版本号的参考序列提案。73 个对象有发布者 MD5 预期，42 个对象只有文件大小预期。已知所选源序列总量不包括 Data 6 和 Data 8。

全部 35 项本地软件包检查均通过，涵盖清单/目录/下载计划一致性、确切文件名和来源路径、数量、当前数据集/参考序列映射、实际 XLSX 和 DOCX 内容、内部链接、完整多 run 文件清单及公开导航。9 项合成软件功能测试也全部通过。测试覆盖计划生成、本地验证/续传行为，以及固定的 BAM 导出规则，包括拒绝缺失质量值的输入。测试没有处理任何真实源 BAM。

部分工作表单元格根据实际 XLSX 数值、本地字体和设定列宽渲染；抽查的文本没有溢出。这些检查不是原生 Excel 渲染或 Word 分页证明。

本软件包不认证源文件可用性、全文件完整性、源文件与参考序列兼容性、完整文库分布或压缩性能。已保存的前缀观察逐项标明，且为非随机样本。参考序列仍是元数据层面的提案。Data 6 仍须确认真实源文件适用性并执行准备；Data 8 的确切全文件产出量未知，且没有发布者校验和。作者署名和软件包许可证仍待确定。
